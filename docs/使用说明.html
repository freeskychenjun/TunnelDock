SECTION 01

快速上手

双击安装包（内置 cloudflared，无任何前置依赖）后，从桌面快捷方式或托盘图标打开 TunnelDock。SmartScreen 提示「未知发布者」时点更多信息 → 仍要运行。

新建发布：点右上角「＋ 新建发布」，填服务名称、目标地址（一般是 127.0.0.1）、端口。访问口令留空会自动生成 8 位 PIN。
启动：卡片上点「启动」。首次建立隧道约 10–30 秒，状态徽章变绿后卡片上出现公网地址与二维码。
手机访问：扫码（或输入地址）→ 出现 TunnelDock 登录墙 → 输入 PIN → 进入你的服务。会话 12 小时内免重复输入。

SECTION 03

固定域名（推荐长期使用）

默认的免费临时地址每次重启都会换。绑定自己的域名后地址永久固定，手机可收藏；自有域名也不受随机子域 DNS 抽风之苦。

准备：一个 Cloudflare 账号 + 一个托管在 Cloudflare 的域名（在其控制台购买，.top/.xyz 年费十几元）。
一次性授权：PowerShell 运行 & "$env:LOCALAPPDATA\Programs\tunneldock\resources\cloudflared.exe" tunnel login， 自动弹浏览器 → 登录 → 选中域名 → Authorize。
绑定：服务卡片「设域名」→ 填子域名（如 nas.你的域名.top）→ 保存 → 启动。
cert.pem 是钥匙

授权生成的 C:\Users\你\.cloudflared\cert.pem 等于你账号里该域名的管理权——不要发给任何人、不要上传。泄露即换：Cloudflare 控制台删除可疑隧道即可止损。

详细图文步骤见分享包内《同事指南-固定域名.md》。

SECTION 04

令牌引导（服务自带门禁时）

有些服务（典型如 dsh web）要求首次访问必须在地址栏带一次性 ?token=，否则返回 401 authentication required。这类服务在卡片上点「令牌引导」，填入打印该令牌的日志文件路径即可：

  • dsh（pm2 托管）：C:\Users\你\.pm2\logs\dsh-web-out.log
  • 其他服务：它控制台/日志里出现 ?token=xxxx 的那个文件

原理：网关收到服务 401 时自动读取该文件里最新一条 token 替你带上，令牌轮换也自动跟上。服务自带账号密码体系的（如 pi-web 的 Basic 认证），直接输它的账号密码即可，无需此功能。

SECTION 05

安全须知

公网地址 = 任何人可达

唯一屏障是 PIN 口令墙。请务必使用 8 位以上口令（卡片「改口令」），不要发布你不愿意暴露的服务；Web 终端、管理后台类服务建议叠加自身账号体系。不用时点「停止」，公网入口立即关闭。

  • 登录失败限速已内置（同 IP 5 次/分钟），但仍建议强口令；
  • 免费临时地址（Quick Tunnel）无可用性保证，正式场景请绑固定域名；
  • 所有凭据（PIN、cert.pem、隧道凭据）只存在你本机，分享安装包不含任何个人信息。
SECTION 06

排障手册

症状原因与解法
502 Bad Gateway目标服务没启动或地址不对（带 http:// 会自动清洗）。在电脑浏览器直访 http://目标:端口 验证服务本身。
页面 401 / authentication required服务自身的门禁：token 类 → 第 04 节令牌引导；账号类 → 输它的账号密码。
手机「找不到服务器」运营商 DNS 对随机子域抽风。手机浏览器开 DoH（Firefox：设置→隐私与安全→DNS over HTTPS）；或 Android「私人 DNS」填 1dot1dot1dot1.cloudflare-dns.com；根治=绑固定域名。
微信能开，QQ/系统浏览器不行微信内核自带 HTTPDNS 绕开了运营商 DNS。给手机设「私人 DNS」（同上）系统级解决；仍慢则 APN 协议改 IPv4。
换网络后全部打不开多为 IPv6 陷阱：DNS 返回 AAAA 优先而 v6 路由不通。诊断口诀：curl -4 通 + curl -6 挂 = IPv6 的锅；解法=关 zone 的 IPv6 Compatibility（免费版需 API）或手机 APN 改 IPv4。
一直「重连中」网络掐了 UDP（QUIC）。0.3.2 起第二次重连自动降级 http2（TCP），等它自愈即可；急的话停用再启动。
页面开了但某插件 import failed「大插件 × 慢网络」：几 MB 的插件在慢隧道上加载超时。换好网络加载一次（成功后进浏览器缓存）；或禁用该插件。
