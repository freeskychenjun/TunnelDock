# TunnelDock 反向隧道 · 同事安装指南

> 适用场景：办公网络封锁了 cloudflared 隧道端口（7844），普通内网穿透工具全部连不上。
> TunnelDock 的「反向隧道」模式走 443 端口反向连接，不受封锁影响。
> 手机在任何网络（流量/家里 WiFi）都能访问你电脑上的服务。

## 一、准备（一次性，约 15 分钟 + 域名费）

1. **注册 Cloudflare 账号**（免费）：https://dash.cloudflare.com/sign-up
2. **买一个域名**（几十元/年，任意注册商），按 CF 提示把域名 NS 托管到 Cloudflare
   （在注册商后台把 Nameserver 改成 CF 给的两条地址，等生效）
3. **创建 API Token**：
   https://dash.cloudflare.com/profile/api-tokens → 创建令牌 → 自定义：
   - 权限：`Zone·DNS·Edit`、`Zone·Workers Routes·Edit`、`Account·Workers Scripts·Edit`
   - Zone 资源：包含你的域名；Account 资源：包含你的账号
   - 创建后**立即复制**（只显示一次）

## 二、安装与配置（一次性，约 3 分钟）

1. 安装 `TunnelDock Setup x.x.x.exe`（下一步装完，托盘出现 ⚓ 图标）
2. 主界面工具栏点 **「反向隧道」**：
   - 粘贴 API Token → 点「验证」（列出你的域名）
   - 选中域名 → 点「部署」（自动完成 DNS + Worker + 路由，约 10-30 秒）
3. 看到「已配置 ✓ 域名」即完成

## 三、日常使用

1. 「＋ 新建发布」：填服务名 + `127.0.0.1` + 端口，传输模式选「反向隧道 wss」
2. 点「启动」→ 状态变绿后出现地址 `https://xxxx.你的域名.com`
3. 手机扫码（卡片上「二维码」）→ 输入 PIN 即可访问
4. 电脑重启：TunnelDock 开机自启并自动恢复全部发布（默认开启）

## 四、常见问题

| 症状 | 处理 |
|---|---|
| 部署报权限错误 | Token 权限没勾全（见一.3 的三项），重新创建 |
| 启动慢/状态一直是"发布中" | agent 在自动轮换边缘节点（网络原因），最长 1-2 分钟，属正常 |
| 手机打不开 | 确认手机用**流量**测试（部分办公/家宽 WiFi 封 CF）；或浏览器开 DoH |
| 想换回普通模式 | 服务卡片上「RT✓」点一下切回 cloudflared（网络不封锁时更快） |
| 换电脑 | 新电脑装好后重跑「反向隧道」向导（同一个 Token+域名即可接管） |

## 五、安全说明

- 每个发布独立 PIN + 登录失败限速（5 次/分钟封 60 秒）
- API Token 用 Windows DPAPI 加密存在本机 `%APPDATA%\TunnelDock\data\account.json`，不会上传
- 公网入口只有你自己域名下的子域，Worker 不暴露任何管理端口
